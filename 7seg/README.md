# 7-segment + Wi-Fi MQTT

- ใช้ UNO R4 WiFi, 7-segment **Common Cathode** พร้อมตัวต้านทาน 220–330Ω **แยกทุก segment**
- A–G ต่อ D2–D8 ตามลำดับ, COM ต่อ GND; ถ้าเป็น Common Anode ต้องกลับลอจิกและเปลี่ยนการต่อวงจร
- ติดตั้ง PubSubClient และใช้ WiFiS3 ที่มากับ UNO R4 WiFi
- Subscribe: `68070131/7seg/set` รับอักขระ 0–9
- Publish: `68070131/7seg/state` ส่งค่าที่ยืนยันแล้ว
- ทดสอบ: ส่ง `7` ไปยัง topic /set → แสดงเลข 7 → ส่ง `7` ไป /state
- ตัวอย่างต่อยอด: นับ 0–9, นับถอยหลัง, แสดงหลักหน่วยของเซนเซอร์, แสดงระดับ 0–9, สั่งเปิด/ปิดผ่าน MQTT, รับค่าจาก keypad แล้วแสดง, ส่งผลการกดปุ่มขึ้นเว็บ, แจ้งเตือนด้วยตัวเลข, เชื่อม MCP9700AE เพื่อแสดงหลักหน่วยอุณหภูมิ
- หากแสดงเลขผิด ให้ตรวจลำดับสาย A–G, ประเภท Common Cathode/Anode และ GND ร่วมกัน
- ถ้าไม่ขึ้นเว็บ ตรวจ Wi-Fi, DNS, broker port 1883 และสิทธิ์เชื่อมต่อ broker
