# เซนเซอร์วัดอุณหภูมิ LM35 — อาร์เรย์และลิสต์

[🏠 หน้าแรก](../../README.md) › [📚 เมนูอาร์เรย์และลิสต์](../README.md)

## ทำอะไร
อ่านค่าจากอุปกรณ์แล้วเก็บ 20 ค่าล่าสุดใน **array วงแหวน** และ **singly linked list** พร้อมกัน ส่ง JSON ขึ้นเว็บ แสดงรายการที่เลือกบน LCD และรับคำสั่งจากเว็บ
เก็บค่าที่แปลงตามหน่วยของเซนเซอร์แล้ว

## ต่อสาย

Vout → A0; Vs → 5V; GND → GND (ตรวจ pinout รุ่นจริง)

LCD I2C 16×2: VCC → 5V, GND → GND, SDA → ขา SDA (A4), SCL → ขา SCL (A5) ใช้ address 0x27 หรือแก้เป็น 0x3F ตามโมดูล ปรับ contrast ก่อนใช้งาน ห้ามใช้ A4/A5 ซ้ำกับเซนเซอร์



## วิธีทำทีละขั้น
1. [ติดตั้งไลบรารี](../../MQTT/LIBRARIES.md#ไลบรารีที่ต้องติดตั้ง) สำหรับ UNO R4 WiFi; ไม่ต้องติดตั้งไลบรารี array/list เพิ่ม
2. เปิด `LM35.ino` และเก็บไฟล์ .h ทั้งหมดในโฟลเดอร์นี้ไว้ข้างกัน
3. แก้ WIFI_SSID/WIFI_PASS, BROKER/PORT แล้ว Upload; Serial Monitor 115200
4. จาก root repo รัน `cd MQTT/web` → `npm ci` → `npm start` แล้วเปิด http://127.0.0.1:3000
5. เลือก **อาร์เรย์และลิสต์ — เก็บประวัติเซนเซอร์** และชื่ออุปกรณ์นี้
6. รอให้มี 3–5 ค่า แล้วเลือกโครงสร้าง/ลำดับและกด “ดูรายการบน LCD” หรือ “ขอประวัติ”
7. ส่ง `{"structure":"list","history_index":2,"request_history":true,"text":"View index 2"}`
8. Serial แสดง RX/ACK/HISTORY; LCD แสดงข้อความเว็บ 5 วินาที แล้วแสดง LIST 2 N=จำนวนค่า และค่าลำดับที่ 2 ตอนรอบอ่านถัดไป
9. กด “ล้างประวัติ” → ได้รายการว่าง แล้วการอ่านครั้งต่อไปจะเริ่มเก็บใหม่

## Topic และ JSON
- บอร์ดส่ง `68070131/collections/LM35/telemetry` พร้อม `history.array` และ `history.list`
- เว็บส่ง `68070131/collections/LM35/command`
- บอร์ดตอบ `/ack` และ `/history`; ขอประวัติไม่อ่านค่าใหม่และไม่เพิ่มจำนวน
- `history_index` = 0..19 จาก **เก่าสุด**; หากยังไม่มีรายการนั้น LCD แสดง INDEX NOT READY
- [รูปแบบคำสั่งและความหมายตัวแปรทั้งหมด](../README.md#คำสั่งจากเว็บ)

## แยกส่วนโค้ด
- `readSensor/sensorSetup`: ตั้งขาและอ่านเซนเซอร์ หน่วยเหมือนตัวอย่าง MQTT เดิม
- `SensorHistory.h`: เก็บ array และ Node pool; append/arrayAt/listAt/clear มีคอมเมนต์ทุกตัวแปร
- `historyJson`: เดินอ่านทั้งสองโครงสร้างแปลงเป็น JSON array (สองโครงสร้างภายในต่างกัน แต่รูปแบบบนสายเป็น JSON array เหมือนกัน)
- `historyTick`: ตอบ snapshot นอก MQTT callback; `received`: ตรวจชนิดคำสั่งแล้วตั้ง state
- `emit`: เก็บค่า, ส่งเว็บ/Serial, แสดงค่าที่เลือกบน LCD; `networkTick`: ต่อใหม่เมื่อหลุด

## ข้อจำกัดของชุดนี้
เก็บ RAM 20 ค่า/ช่อง ปิดเครื่องข้อมูลหาย; ค่าใหม่แทนเก่าสุดเมื่อเต็ม; NaN/timeout ไม่เพิ่มประวัติ; ไม่มีคิว telemetry ส่งย้อนหลังตอน offline แต่ขอ history ที่ยังอยู่ใน RAM ได้เมื่อกลับมาออนไลน์
Keypad เพิ่มเฉพาะปุ่มใหม่ เก็บ ASCII; ButtonEvents เก็บ snapshot และกด/ปล่อย จึงไม่ใช่หนึ่งรายการต่อหนึ่งครั้งกด; ปุ่มแบบ Button อ่านเป็นรอบ ใช้ ButtonEvents ถ้าต้องการขอบกดพร้อม debounce
DHT ส่ง 2 ช่องและ LCD แสดงช่องที่อ่านล่าสุด; ข้อความไทยบน LCD ROM ทั่วไปไม่รองรับ ใช้ text ASCII
NTC/TTC05103 ให้ใช้วงจรและค่า Beta ตามไฟล์ตัวอย่างเดิม ห้ามสลับวงจร/สูตร
ยังไม่ได้ compile ด้วย Arduino toolchain หรือทดสอบวงจรจริงในสภาพแวดล้อมนี้
