# ประยุกต์ LAB — Arduino UNO R4 WiFi + MQTT

ชุดโจทย์ประยุกต์จาก 12 LAB ในสไลด์ แยกไฟล์ Sketch ตาม Publish, Subscribe, และสองทาง เพื่อเตรียมสอบและต่อเว็บจริง โดยเก็บโค้ดต้นฉบับไว้เหมือนเดิม

**Wi-Fi:** EDOK · **MQTT Host:** `phycom.it.kmitl.ac.th` · **Port:** `1883` · **Topic ทุกไฟล์:** `68070131/applied/`

> ⚠️ Repository นี้เป็น Public และรหัสผ่านที่โจทย์ระบุถูกใส่ไว้ใน Sketch ตัวอย่าง อย่าใช้รหัสผ่านนี้กับเครือข่ายที่มีข้อมูลสำคัญ และควรย้ายไปเก็บในไฟล์ secrets ที่ไม่ commit หากนำไปใช้จริง

## โครงสร้าง MQTT ที่เว็บและบอร์ดใช้ตรงกัน

```text
68070131/applied/lab01/pub/data     ← บอร์ดส่งเลข
68070131/applied/lab01/sub/set      → เว็บสั่งเลข
68070131/applied/lab01/both/set     → เว็บสั่งเลข
68070131/applied/lab01/both/data    ← บอร์ดส่งข้อมูล
68070131/applied/lab01/both/state   ← บอร์ดตอบ OK/ERROR
```

เปลี่ยน `lab01` เป็น `lab02` ถึง `lab12` ตามต้องการ และเปลี่ยนโหมด `pub`, `sub`, `both` ให้ตรงกับไฟล์ Sketch

## เปิดเว็บควบคุมและติดตาม MQTT

- [แดชบอร์ดประยุกต์ LAB](เว็บจำลอง/index.html) · [Node.js MQTT Bridge](เว็บจำลอง/server.js)
- บนคอมพิวเตอร์เข้าโฟลเดอร์ `ประยุกต์ LAB/เว็บจำลอง` แล้วรัน `npm install` ตามด้วย `npm start` จากนั้นเปิด `http://localhost:3001`
- GitHub Pages เสิร์ฟ HTML ได้ แต่ **ไม่สามารถเชื่อม MQTT TCP :1883 โดยตรงได้** จึงต้องมี Bridge ที่รันอยู่จริง หน้าเว็บไม่ส่งข้อมูลหาก Bridge ยังไม่เชื่อมต่อ

## ตรวจ Compile และผลทดสอบ

- [GitHub Actions: ตรวจ Compile](../.github/workflows/compile-applied-labs.yml) คอมไพล์ Sketch ทุกไฟล์สำหรับ `arduino:renesas_uno:unor4wifi` ทุกครั้งที่ push โฟลเดอร์นี้
- ผลทดสอบที่คาดหวังอยู่ใน README ของแต่ละ Sketch และ [คู่มือรวมผลทดสอบ](ผลทดสอบที่คาดหวัง.md)
- **Compile ผ่าน** ไม่เท่ากับ **ทดสอบจริงผ่าน**: ต้องต่อบอร์ด ตรวจไฟ LED, LCD, เซนเซอร์ และการเชื่อม Broker จริง
- หาก Wi-Fi/MQTT ไม่เชื่อม จะยังใช้งานฮาร์ดแวร์ภายในโหมดส่ง/สองทางได้ แต่จะไม่มีข้อมูลใหม่บนเว็บจนกว่าจะเชื่อมได้

## ข้อจำกัดความถูกต้องของฮาร์ดแวร์

- 7-Segment ในชุดนี้เป็น **Common Cathode 1 หลัก** ต้องต่อ R 220–330Ω ต่อ segment; หากเป็น Common Anode ต้องกลับลอจิกและแก้ COM
- ขา TMP36 ตรวจ datasheet รุ่นจริงก่อนต่อไฟเพื่อป้องกันเซนเซอร์ร้อน/เสียหาย; สูตร `(Vout - 0.5) × 100` บน ADC 12-bit อ้างอิงแรงดัน 5V ตัวอย่าง
- แสดงบน LCD I2C Address `0x27`; ถ้าจอไม่ขึ้นให้ I2C scan และปรับค่าที่ constructor
