## เกณฑ์ตรวจผ่าน

1. Arduino IDE / CI ต้อง Compile ด้วย FQBN `arduino:renesas_uno:unor4wifi` และไลบรารีที่ตรงกับโค้ด
2. Serial Monitor 115200 แสดง Prefix และ MQTT connected เมื่อ Wi-Fi/Broker พร้อม
3. การส่งและรับต้องใช้ Topic ตรงตามโหมด รวมถึงไม่วน Subscribe กลับเข้าข้อมูล Publish ตนเอง
4. ทดสอบการหลุดเครือข่ายและเชื่อมใหม่, ส่งคำสั่งผิดค่า, และ sensor timeout (เช่น Ultrasonic NO_ECHO)
5. ตรวจผลที่อุปกรณ์จริง; ภาพ SVG เป็นผังสายอ้างอิง ไม่ใช่ผลจำลองไฟฟ้าหรือภาพทดสอบบน breadboard
