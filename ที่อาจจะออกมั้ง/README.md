# ที่อาจจะออกมั้ง — ชุดฝึก Mock 6 ข้อ + โจทย์ประยุกต์ 12 ข้อ

นี่เป็น **แบบฝึกคาดการณ์** ไม่ใช่ข้อสอบจริงหรืองานที่ผู้สอนยืนยันว่าจะออก

## ค้นหาโจทย์จากชื่อและเลือกเซนเซอร์

[🌐 เปิดเว็บค้นหาโจทย์บน GitHub Pages](https://kmitl68070131.github.io/LAB-Arduino-Phycom/ที่อาจจะออกมั้ง/web/) · [💻 เปิดไฟล์เว็บ](web/index.html)

หน้าเว็บมีช่องค้นหาและ Checkbox เลือกเซนเซอร์หลายตัว เช่น Ultrasonic + LCD + LED พร้อมเลือกให้กรองแบบตรงทุกตัวหรือบางตัวได้ ผลลัพธ์กดเปิดโค้ด รูปวงจร และวิธีต่อสายได้ทันที

## ค่าที่ใช้ทุก Sketch

- Board: Arduino UNO R4 WiFi
- Wi-Fi: `EDOK`, password: แก้ตัวแปร `WIFI_PASS` ตามที่โจทย์ให้
- Broker: `phycom.it.kmitl.ac.th:1883`
- ทุก Topic ขึ้นต้น `68070131/`
- LCD: 16×2 แบบ I2C VCC→5V, GND→GND, SDA→SDA, SCL→SCL
- Arduino Library: `WiFiS3`, `MQTTClient` (256dpi), `Wire`, `LiquidCrystal_I2C`

| 07–18 | ฝึกผสมเซนเซอร์ | [โฟลเดอร์](02_โจทย์ประยุกต์_12ข้อ/) | 68070131/guess/XX/data | 68070131/guess/XX/set |

ทุกโค้ดมีคอมเมนต์ละเอียดด้านบนไฟล์ แบ่ง 10 ส่วน พร้อมบรรทัดแก้ Topic, สายต่อ, การคำนวณและผลคาดหวัง

**เว็บบน GitHub Pages** ใช้ค้นหาได้โดยไม่ต้องรัน Node.js; การรับส่ง MQTT จริงให้เปิด terminal ใน `web` แล้วรัน `npm install`, `npm start` และเข้า `http://127.0.0.1:3006` เพราะ Browser ไม่สามารถเชื่อม MQTT TCP 1883 ได้โดยตรง

การ Compile ยังต้องดูผลที่แท็บ Actions; โค้ดไม่ได้ผ่านการทดสอบอุปกรณ์จริง
