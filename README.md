# LAB-Arduino-Phycom

📘 **Interactive Arduino UNO R4 WiFi Physical Computing Handbook**

เปิดคู่มือแบบเลือกหัวข้อได้: **[เปิดคู่มือ Arduino](https://kmitl68070131.github.io/LAB-Arduino-Phycom/)**

> หากลิงก์ยังไม่แสดงเว็บ ให้เปิด GitHub Repository → Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save

## คู่มือมีอะไรบ้าง?
- เมนูหัวข้อ 14 หมวดพร้อมช่องค้นหาและลิงก์ตรงไปยังแต่ละบท
- วิธีต่อสาย การทำงาน คำสั่งสำคัญ และตัวอย่าง Arduino Code พร้อมคัดลอก
- หมวด: Arduino, LCD I2C, Keypad, Ultrasonic, TMP36, Thermistor, Potentiometer, RGB LED, 7-Segment, Button/PIR, Wi-Fi, MQTT, DHT, LDR
- ลิงก์สู่ไฟล์ LAB ต้นฉบับใน `Phycom lab EXAM/`
- รองรับมือถือและคอมพิวเตอร์ด้วย `index.html` (ไม่ต้อง Build)

## วิธีใช้งาน
1. เปิด `index.html` หรือเว็บไซต์ GitHub Pages
2. เลือกหัวข้อจากแถบด้านซ้ายหรือค้นหาชื่อเซนเซอร์
3. อ่านการต่อสายและวิธีใช้ พร้อมคัดลอกตัวอย่างโค้ด
4. กดเอกสารต้นฉบับเพื่ออ่าน Sketch แบบเต็มและคำอธิบายเพิ่มเติม

**หมายเหตุ:** ตัวอย่างแต่ละหมวดเป็นวงจร/Sketch อิสระ ควรตรวจสอบแรงดันและลำดับขาอุปกรณ์จริงก่อนใช้งาน เนื้อหาโค้ด LAB เดิมไม่ได้ถูกแก้ไข
