# MCP9700AE + Wi-Fi MQTT

- ใช้ UNO R4 WiFi, MCP9700AE ต่อ VDD=5V, GND=GND, VOUT=A3 (ตรวจ pinout แพ็กเกจก่อนต่อ)
- ติดตั้ง PubSubClient และใช้ WiFiS3
- Publish: `68070131/tmp/temperature` ทุก 2 วินาที เป็นค่าองศาเซลเซียส
- สูตร: `T(°C)=(Vout(mV)-500)/10` เป็นสูตร nominal; ค่า ADC 10-bit 0–1023
- ปรับ VREF ให้ตรงกับแรงดันอ้างอิงจริง และ OFFSET_C หลังเทียบเครื่องวัดอุณหภูมิ
- ตัวอย่างต่อยอด: ส่งอุณหภูมิเป็น JSON, ค่าเฉลี่ยเคลื่อนที่, ค่าสูงสุดต่ำสุด, แจ้งเตือนเกินเกณฑ์, รับ threshold ผ่าน MQTT, รับคำสั่งปรับ calibration, แสดงค่า LCD I2C, ส่งให้ 7-segment, ควบคุม LED/RGB ตามระดับอุณหภูมิ, บันทึกกราฟบนเว็บ
- ทดสอบ: เปิด Serial Monitor 115200 → ดูค่า °C → ตรวจข้อความที่ topic /temperature
- ค่าอุณหภูมิผิด: ตรวจ VOUT, VREF, pinout, กราวด์ร่วม และอย่าต่อ VOUT เข้าขาไฟเลี้ยง
- Broker อาจต้องใช้เครือข่ายมหาวิทยาลัยหรือ VPN หาก DNS/การเชื่อมต่อจากภายนอกไม่ผ่าน
