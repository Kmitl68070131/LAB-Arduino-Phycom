## ต่อสาย

ใช้ปุ่ม **momentary normally open 2 ขา** (ปล่อยแล้ววงจรเปิด กดแล้วต่อถึงกัน)

| อุปกรณ์ | ต่อที่ |
|---|---|
| ปุ่ม ขาที่ 1 | Arduino UNO R4 WiFi **D4** |
| ปุ่ม ขาที่ 2 | **GND** |
| LCD VCC | 5V |
| LCD GND | GND |
| LCD SDA | SDA / A4 |
| LCD SCL | SCL / A5 |

ปุ่ม 2 ขาทั่วไปไม่มีขั้ว สลับสองขาได้ โค้ดใช้ `INPUT_PULLUP` จึงไม่ต้องใส่ R pull-up เพิ่ม: **ปล่อย=HIGH, กด=LOW** โค้ดแปลงเป็น `pressed=true/value=1` ให้เว็บอ่านง่าย ไม่ต่อปุ่มเข้ากับ 5V ในวงจรนี้

หากใช้ปุ่ม 4 ขาแทน ให้เลือกคนละฝั่งที่ปล่อยแล้วไม่ต่อถึงกัน ตรวจ continuity ด้วยมัลติมิเตอร์ หากเลือกขาที่ต่อกันอยู่แล้วจะอ่านว่ากดตลอด

## ติดตั้งและเปิดเว็บ

1. ติดตั้ง Arduino UNO R4 Boards แล้วเลือก UNO R4 WiFi และ Port
2. ติดตั้ง [ไลบรารีตามตาราง](../LIBRARIES.md#ไลบรารีที่ต้องติดตั้ง): MQTT by Joel Gaehwiler, ArduinoJson 7, LiquidCrystal I2C; WiFiS3/Wire มากับบอร์ด
3. เปิด `ButtonEvents.ino` โดยมี `Statistics.h` และ `ButtonDebounce.h` อยู่โฟลเดอร์เดียวกัน
4. แก้ `WIFI_SSID`, `WIFI_PASS`; broker ค่าเริ่ม `phycom.it.kmitl.ac.th:1883` ตรวจว่าเครือข่ายเข้าได้
5. ต่อ LCD address 0x27 (เปลี่ยนเป็น 0x3F ถ้าโมดูลใช้ค่านี้) แล้ว Upload เปิด Serial Monitor **115200**
6. เปิด terminal ที่ root repository:

```sh
cd MQTT/web
npm ci
npm start
```

7. เปิด **http://127.0.0.1:3000** บนเครื่องที่รัน Node แล้วเลือกโหมด **รับส่งข้อมูลเซนเซอร์และปุ่มกด (MQTT)** และอุปกรณ์ **ปุ่มกด 2 ขา ส่งกด–ปล่อยและจำนวนครั้งขึ้นเว็บ** (รหัส `ButtonEvents`)

เว็บต้องผ่าน Node bridge ไม่เปิดไฟล์ HTML ตรงจาก GitHub Pages เพราะ browser ต่อ MQTT TCP 1883 โดยตรงไม่ได้

## ทดลองกดอย่างไรให้ขึ้นเว็บ

| สิ่งที่ทำ | สิ่งที่ควรเห็น |
|---|---|
| รอเริ่มระบบ ไม่กดปุ่ม | snapshot `pressed=false`, `value=0` |
| กดค้างประมาณ 0.1–1 วินาที | `event=pressed`, `pressed=true`, `value=1`, จำนวนกดเพิ่ม 1 |
| กดค้างต่อ | snapshot สถานะกดตาม interval แต่จำนวนกดไม่เพิ่มซ้ำ |
| ปล่อย | `event=released`, `pressed=false`, `value=0` |
| กด–ปล่อยอีก 3 ครั้ง | `press_count` เพิ่มอีก 3 |

เว็บแสดงแถบ **กำลังกด / ปล่อยปุ่ม / จำนวนกด** และ JSON ล่าสุด; Serial แสดง `TX {...}`; LCD แสดงสถานะ 1/0 (เมื่อไม่ได้แสดงข้อความเว็บ)
Debounce ต้องนิ่ง 30 ms จึงนับ 1 ครั้ง แต่ WiFiS3/connect อาจบล็อกการอ่านระหว่าง reconnect การกดสั้นมากช่วงนั้นอาจหาย ตัวอย่างนี้ไม่ใช่ระบบนับ pulse ความเร็วสูง

## ข้อมูลที่เว็บได้รับ

Topic **`68070131/mqtt/ButtonEvents/telemetry`**

```json
{"sensor":"ButtonEvents","channel":"ButtonEvents","unit":"state","pressed":true,"event":"pressed","press_count":1,"uptime_ms":5000,"valid":true,"value":1}
```

| ฟิลด์ | ความหมาย |
|---|---|
| pressed | true กำลังกด / false ปล่อย |
| event | pressed=ขอบกด, released=ขอบปล่อย, snapshot=ส่งสถานะเป็นระยะ |
| press_count | จำนวนขอบกดที่กรองแล้วตั้งแต่เปิดบอร์ด เริ่ม 0 ไม่เก็บใน EEPROM |
| uptime_ms | เวลาตั้งแต่เปิดบอร์ด หน่วย ms ไม่ใช่เวลาปฏิทิน |
| value | 1 กด / 0 ปล่อย |
| valid | ข้อมูลสถานะอ่านได้ |

เริ่มเปิดบอร์ดขณะกดค้างไม่เพิ่มจำนวนจนกว่าจะปล่อยแล้วกดใหม่ เมื่อเน็ตหลุดจำนวนกดยังเพิ่มถ้า loop อ่านทัน แต่เหตุการณ์ไม่ได้เข้าคิวส่งย้อนหลัง เว็บจะได้สถานะ/จำนวนปัจจุบันจาก snapshot หลังเชื่อมใหม่ ใช้ QoS 0 จึงไม่รับประกันทุกขอบถึงเว็บ

## ส่งกลับจากเว็บ

ใส่ JSON ในเว็บแล้วกด **ส่ง JSON ไปบอร์ด**:

```json
{"text":"Button received!","interval_ms":2500,"reset":false}
```

ส่งไป **`68070131/mqtt/ButtonEvents/command`** → Serial แสดง RX ทั้งก้อน → LCD แสดง WEB RX กับ text 16 ตัวแรก 5 วินาที → เว็บได้รับ **`.../ack`**
`interval_ms` คุม snapshot (2500–60000 ms) ไม่ได้หน่วงขอบกด; `reset` ล้างเฉพาะสถิติ ไม่ล้าง press_count; หากต้องเริ่มนับใหม่กด Reset ที่บอร์ด คำสั่ง text ใช้ ASCII บน LCD

## ส่วนโค้ดและตัวแปร

| ส่วน | หน้าที่ |
|---|---|
| ButtonDebounce.h | แยกตัวกรองการเด้งที่ทดสอบบนคอมพิวเตอร์ได้ |
| raw / stable | ค่าทันทีก่อนกรอง / ค่านิ่งหลังกรอง |
| changedAt / DEBOUNCE_MS | เวลา raw เปลี่ยน / เวลารอ 30 ms |
| button / changed | ตัวจัดการสถานะ / รอบนี้เกิดขอบใหม่หรือไม่ |
| pressCount / eventName | จำนวนกด / ชนิดข้อความที่จะส่ง |
| networkTick / received | reconnect และรับคำสั่งเว็บ |
| emit / line | serialize+publish+Serial / เติมข้อความ LCD ให้ครบแถว |
| lastSample / intervalMs | เวลาส่งล่าสุด / ระยะ snapshot |

ดูคอมเมนต์ตัวแปรเครือข่ายและ JSON เพิ่มใน `.ino` [ปุ่มแบบอ่านเป็นรอบเดิม](../Button/README.md) ยังใช้ได้ แต่การกดสั้นระหว่างรอบอาจไม่ถูกอ่าน ใช้ ButtonEvents เมื่อต้องการติดตามกด–ปล่อย

## แก้ปัญหา

- **Serial มี TX แต่เว็บไม่ขึ้น:** ตรวจ NOT SENT, เลือก ButtonEvents/โหมด MQTT ให้ตรง, เปิด Node bridge และให้บอร์ด/Node เข้าถึง broker เดียวกัน
- **กดแล้วเป็น 0 ตลอด:** ตรวจ D4/GND และชนิดปุ่ม NO; ปิดไฟก่อนย้ายสาย
- **ขึ้น 1 ตลอด:** สายชอร์ต GND หรือปุ่ม 4 ขาต่อผิดฝั่ง
- **กดครั้งเดียวเพิ่มหลายครั้ง:** ตรวจหน้าสัมผัส/สายหลวม ปรับ DEBOUNCE_MS เป็น 50 ตามปุ่มจริง
- **LCD ไม่ขึ้น:** ตรวจ address, SDA/SCL และ contrast; ใช้ 115200 บน Serial
